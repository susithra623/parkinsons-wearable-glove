# AI-Powered Parkinson's Screening Glove

## Project Overview
This project proposes a multimodal wearable glove designed to support preliminary Parkinson's motor-function screening and monitoring. The system aims to collect hand-movement data using sensors and analyze movement patterns with AI-assisted software.

## Problem Statement
Parkinson's disease can affect hand movement, coordination, and motor control. Periodic clinical assessments may not capture every change in a person's everyday motor function. This project explores a wearable approach to recording selected hand-movement indicators for review over time.

## Proposed Features
- Hand tremor and movement monitoring using an IMU sensor.
- Finger-bending measurement using flex sensors.
- Grip-related measurement using force sensors.
- ESP32-based sensor data collection.
- AI-assisted movement-pattern analysis.
- Dashboard for assessment summaries and historical trends.

## Proposed Technologies
- Hardware: ESP32 and compatible motion, flex, and force sensors.
- Programming: Python and embedded C/C++, subject to implementation.
- Analysis: Machine learning for movement-feature analysis.
- Interface: A web-based dashboard.
- Design: CAD modelling and circuit design tools.

## Current Project Status
The project is currently in the planning and documentation stage. Hardware assembly, CAD development, software implementation, and experimental validation are planned future activities.

## Intended Use
The proposed system is intended to support preliminary screening and motor-function monitoring. It is not a replacement for professional medical assessment or diagnosis.
