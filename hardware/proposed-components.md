# Proposed Hardware Components

| Component | Intended Purpose |
|---|---|
| ESP32 development board | Sensor data collection and communication |
| IMU sensor | Measure hand movement and orientation |
| Flex sensors | Measure finger bending |
| Force sensor | Measure grip-related pressure |
| Battery and charging circuit | Proposed portable power supply |
| Wearable glove | Hold and position the sensors |

The component list is preliminary. Exact models, compatibility, power requirements, and costs must be confirmed before procurement and assembly.
