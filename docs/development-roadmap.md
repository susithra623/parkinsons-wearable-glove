# Development Roadmap
## Current Status
The project is currently in the planning and documentation stage.
## Planned Phases
1. Research Parkinson's-related motor symptoms and existing screening approaches.
2. Select suitable sensors and design the proposed wearable glove.
3. Develop the ESP32-based sensor data collection system.
4. Build a data-processing pipeline and investigate suitable AI/ML methods.
5. Develop a dashboard for viewing measurements and historical trends.
6. Test sensor reliability, usability, and model performance.
## Expected Result
A prototype for collecting and visualizing hand-movement measurements, subject to development and evaluation.
All phases listed above are planned activities and have not yet been completed.
