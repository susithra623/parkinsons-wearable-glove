# Proposed System Architecture
1. **Sensing:** The proposed IMU, flex sensors, and force sensor capture hand-movement indicators.
2. **Data collection:** The ESP32 is planned to collect sensor readings.
3. **Data transfer:** Wi-Fi or Bluetooth communication will be evaluated.
4. **Processing:** Software will clean and organize the collected readings.
5. **Analysis:** AI/ML methods will be investigated for movement-pattern analysis.
6. **Visualization:** A planned dashboard will display measurements and historical trends.
7. **Review:** Results may support discussion with a qualified healthcare professional.
This is a proposed architecture, not a verified or operational system. It is not intended to independently diagnose Parkinson's disease.
