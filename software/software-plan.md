# Proposed Software Plan
## Embedded Software
C/C++ is proposed for interfacing sensors with the ESP32 and collecting readings.
## Data Processing and AI
Python is proposed for cleaning sensor data, extracting movement features, and investigating suitable machine-learning models.
## Dashboard
HTML, CSS, and JavaScript are proposed for a dashboard that displays measurements and trends across sessions.
## Evaluation
The future system will be evaluated using appropriate data, defined performance metrics, and documented limitations.
No software implementation or model evaluation has been completed yet.
